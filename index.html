📖 Rummikub 拉密規則與雙牌池說明

1. 自動雙牌池判定（Dual Deck System）

• 2 ~ 4 人開局：自動採用標準 106 張牌池（4色 × 13點 × 2組 = 104張正常牌 + 2張 Joker）。

• 5 ~ 6 人開局：自動升級為六人版 160 張牌池（4色 × 13點 × 3組 = 156張正常牌 + 3張 Joker = 159張底層配置）。

2. Joker 在公桌組內的「動態語意排序演算法」

• 組牌（Group）：同數不同色，Joker 置於正常牌末端。

• 順組（Run）：同色連續數，系統動態推算 Joker 代表的正確虛擬點數，精準插入缺口（如：紅3 ➔ 紅4 ➔ Joker(5) ➔ 紅6），確保桌面始終整齊正確。

3. 嚴格 30 點破冰與公桌安全鎖

• 首次出牌（破冰）打出的組合總點數必須 ≥ 30 點。

• 未破冰前公桌全面鎖定：無法碰觸或挪用公桌牌組，只能純由手牌組成全新合法牌組打出。

4. 出牌 / 抽牌二選一防呆機制

• 若已破冰玩家本回合未打出手牌且桌面未變更，點擊「結束回合」時，系統自動強制幫該玩家抽一張牌並切換回合，杜絕跳過抽牌漏洞！

🚀 GitHub Pages / 靜態主機 3 步部署指南

這是一個 100% 獨立自包含的單一 HTML 檔案

所有 CSS 樣式、JavaScript 邏輯、牌組運算演算法與公開 MQTT 訊號連線皆已封裝在此檔案中，不需要任何 Node.js 伺服器或後端資料庫，放上任何靜態網站主機（GitHub Pages、Cloudflare Pages、Vercel、Netlify）即可即時跨國連線遊玩！

步驟 1：下載或取得此 index.html

點擊頂部右上角的「💾 下載單檔」按鈕，即可將完整的 index.html 儲存至您的電腦中。

步驟 2：上傳至 GitHub 倉庫

1. 在 GitHub 上建立一個新的公開倉庫（Repository），例如命名為 rummikub。

2. 在網頁上點擊 Add file ➔ Upload files，將下載的 index.html 直接拖曳上傳，並點擊綠色的 Commit changes。

步驟 3：開啟 GitHub Pages 服務

1. 進入該倉庫的 Settings ➔ Pages。

2. 在 Build and deployment 區塊下的 Branch，選擇 main 分支與 / (root) 目錄，點擊 Save。

3. 等待約 30~60 秒刷新頁面，即可看到您專屬的遊戲網址（例如：https://您的帳號.github.io/rummikub/）！


🌟 連線方式：將該網址發送給好友，大家在手機或電腦點開，輸入相同的「自訂房號（Room ID）」即可立即跨裝置聯機對戰！
